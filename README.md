# superintelligencesg.com

Public home and Singapore AI Navigator for the Superintelligence SG three-domain initiative.

- `index.html` introduces the Navigator, Lab and Commons.
- `directory.html` combines a small public reference index with live self-published Commons profiles.
- Public references are starting points, not rankings, endorsements or a claim of complete coverage.

Review organization-specific public claims before adding them. Community profiles remain self-submitted and are labelled at result level.
